# 🌦️ Weather App

A web-based weather application for searching weather information through a simple interface.

## 🎯 Objectives
- Build a practical web application
- Work with weather data
- Practice JavaScript and DOM interaction
- Present information through an interactive UI

## 🚀 Features
- 🔍 Weather search
- 🌡️ Weather information display
- 🖥️ Interactive interface
- 📱 Responsive-friendly layout

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🔄 Workflow
User searches a location → JavaScript processes the request → weather information is retrieved → UI displays the result.

## ▶️ Run
Open index.html in a browser or serve the project with a local web server.

## 🔮 Future Scope
- Multi-day forecast
- Geolocation
- Weather charts
- Multiple units
